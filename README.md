# SAP Integration Suite development

[Email to Datasphere project and setup](EmailToDatasphere/README.md)

[Download iFlow ZIP](EmailToDatasphere/dist/EmailToDatasphere.iflow.zip)

For SAP Git Import, select repository `SAP_IS_DEV`, branch `main`, and integration flow **EmailToDatasphere**.

Maps Cronacle alerts to P_CHAIN, Status, Reason, Date and Time with a required alphanumeric ID. Mail/JDBC configuration and SAP tenant validation are required.
